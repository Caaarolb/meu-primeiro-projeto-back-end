Este projeto foi desenvolvido como parte do curso **Back-End | Minha Primeira API!**, oferecido pela **[Eu ProgrAmo](https://euprogramo.thinkific.com/courses/curso-back-end-minha-primeira-api)**. Durante o curso, aprendi os fundamentos do desenvolvimento back-end, incluindo a criação de uma **API REST** utilizando **Node.js** e **Express**.

---

## 📚 Conteúdos Abordados no Curso

No curso, foram estudados os seguintes tópicos principais:

1. **Introdução ao Back-End**  
   - O que é back-end e qual sua importância no desenvolvimento de sistemas.
   
2. **Node.js e NPM**  
   - Instalação e configuração do Node.js.  
   - Utilização do **NPM** (Node Package Manager).

3. **Criação de uma API com Express**  
   - Instalação e configuração do **Express**.  
   - Estruturação de rotas, controllers e arquivos.

4. **Operações CRUD**  
   - **Create** (criar), **Read** (ler), **Update** (atualizar), **Delete** (deletar).  
   - Implementação de endpoints RESTful.

5. **Testando a API**  
   - Utilização do **Postman** ou **Insomnia** para testar os endpoints.

6. **Boas práticas de desenvolvimento**  
   - Estruturação do projeto.  
   - Modularização do código.

---

## 💻 Tecnologias Utilizadas

As principais tecnologias utilizadas no projeto incluem:

- **JavaScript**: Linguagem de programação principal.
- **Node.js**: Ambiente de execução para rodar o código back-end.
- **Express**: Framework minimalista para criação de APIs.

---

## ✅ Pré-requisitos

Antes de começar, certifique-se de ter os seguintes itens instalados na sua máquina:

- [Node.js](https://nodejs.org) (versão LTS recomendada)
- [Git](https://git-scm.com)
- Um cliente para testar as APIs, como [Postman](https://www.postman.com) ou [Insomnia](https://insomnia.rest).
